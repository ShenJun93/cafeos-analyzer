CafeOS Analyzer · KiotViet workflow

Đã dùng KiotViet? Phân tích file bán hàng mà không cần đổi POS.

KiotViet F&B hỗ trợ xuất danh sách hóa đơn và file chi tiết. CafeOS dùng export CSV/XLSX làm lớp phân tích độc lập: deterministic metrics trước, rồi mới phát hiện thay đổi đáng chú ý.

Mở Analyzer

Workflow

1. Xuất dữ liệu

Trong KiotViet F&B, vào Giao dịch → Hóa đơn và dùng chức năng Xuất file. Nếu có lựa chọn dữ liệu chi tiết theo hàng hóa, loại item-level thường hữu ích hơn cho phân tích product mix.

2. Upload local/public validation build

CafeOS kiểm tra sheet/header, yêu cầu xác nhận khi mapping không chắc chắn và không tự suy đoán cột bắt buộc.

3. Đối soát trước khi tin insight

So net sales và số đơn với báo cáo gốc. Chỉ khi metric khớp mới dùng insight để thảo luận với operator.

CafeOS hiện phân tích gì?

Net sales, orders, AOV, customer-identification coverage, repeat rate khi có customer identifier, store/daypart comparison và một số decline detectors có baseline evidence.

Validation build, chưa phải connector KiotViet realtime và chưa claim tương thích với mọi biến thể Excel. File thật vẫn phải qua reconciliation.

Nguồn workflow export: tài liệu hướng dẫn KiotViet F&B về Hóa đơn/Xuất file.
