Sapo FnB cho phép xuất nhiều báo cáo ra Excel. Một số báo cáo của hệ sinh thái Sapo giới hạn 20.000 dòng mỗi lần xuất; CafeOS validation engine đã có multi-file overlap deduplication để xử lý kiểu workflow này.

Mở Analyzer

Workflow

1. Chọn report phù hợp

Ưu tiên report bán hàng/item-level có ngày, đơn, sản phẩm, số lượng, doanh thu và chi nhánh nếu có.

2. Nếu report quá lớn, chia theo thời gian

Export nhiều file theo kỳ. CafeOS batch mode có thể merge file overlap mà không nhân đôi line đã nhận diện.

3. Reconcile

Đối chiếu tổng doanh thu/số đơn với Sapo trước khi dùng insight. Import thành công không đồng nghĩa metric đã đáng tin.

Không phải connector realtime

Trang này chỉ mô tả validation workflow qua Excel. CafeOS chưa claim general-purpose Sapo FnB API connector hoặc compatibility với mọi mẫu export.
