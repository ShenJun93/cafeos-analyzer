Field note / ICP
3—15

Phù hợp nhất với ai?

Validation hiện nhắm tới owner/operator chuỗi cafe 3–15 cửa hàng. Quán một cửa hàng vẫn có thể dùng Analyzer, nhưng không thuộc target ICP của scorecard hiện tại.

Mục tiêu hiện tại không phải thay POS, CRM hay hệ thống vận hành hiện có; mục tiêu là kiểm chứng liệu evidence này có đủ mới, đáng tin và hữu ích để operator muốn dùng lại.

Nếu bạn là owner/HQ đang vận hành 3–15 cửa hàng, CafeOS đang nhận đăng ký tham gia nghiên cứu Control Tower E1. Phần Control Tower chỉ dùng dữ liệu demo synthetic — không phải dữ liệu cửa hàng của bạn. Biểu mẫu GitHub là công khai; không đăng tên, thông tin liên hệ, tên quán, file bán hàng hay thông tin khách hàng.

Privacy boundary

Quyền riêng tư khi validation

Public validation preview xử lý file tạm thời trong request và không lưu file vào database/object storage. Preview giới hạn 4 MB/file.

Với file lớn hoặc dữ liệu nhạy cảm, dùng local validation kit; compatibility profile không chứa row values và validation pack dùng HMAC để pseudonymize identifiers.
