# Security Policy

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, real merchant exports, customer PII, HMAC keys, or security-sensitive reproduction data in a public issue.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If that feature is unavailable, open a minimal public issue stating only that you need a private security contact; do not include sensitive details.

## Data handling

This public repository must contain synthetic fixtures only. Real merchant datasets and field-validation evidence belong outside the public repository.

## Supported branch

Security fixes target the current `main` branch while CafeOS Analyzer is pre-1.0.
